# STmall 0.2.6

首个公开发布版本。

## 下载

- APK：`STmall_0.2.6.apk`
- SHA-256：`B4793226D11372C422CDC5D7AF29A3740D3AAC78DE3915A39BD45D29F92CEF70`
- 包名：`com.rea.campuslite`
- 最低系统：Android 8.0（API 26）

升级已有安装时请直接覆盖安装。请勿卸载旧版，否则本地登录态和门锁凭证会被
系统一并删除。

## 包含功能

- 智能宿舍、校园饮水、扫一扫和离线蓝牙门锁。
- 日间、跟随系统和纯黑模式。
- 可配置首页模块和响应式液态玻璃底栏。
- 登录态同步、订单和地址官方页面跳转。
- STmall 自己的 GitHub 更新源。
- 完整使用教程、第三方来源与安全说明。
