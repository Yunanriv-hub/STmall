# STmall 0.3.4

真实液态玻璃升级：

- 改用 Kyant0 Backdrop 官方渲染路径，不再只靠颜色渐变模拟玻璃。
- 页面背景先捕获为图层，玻璃控件再实时采样、增艳、模糊和折射。
- Android 13 及以上为卡片、圆钮、开关门圆钮和底部选中胶囊启用透镜。
- 首页模块、图标底盘、一键开门、双入口卡、设置卡及 NFC/扫码页统一材质。
- 慧生活控制页底栏与选中胶囊使用双层玻璃，能透出并模糊后方内容。
- 底部胶囊支持跟手拖动，选中胶囊、图标和渐变颜色连续移动。
- 松手按最近标签弹簧吸附，并播放页面滑入与滑出动画。
- 增加跨控件连续可见的柔和背景光斑，避免玻璃只呈现为静态磨砂贴片。
- 修复暗黑模式下透明页面文字颜色错误造成的黑字压黑背景。
- 仅启用“一键开门”时，把开门圆钮固定到更方便触达的中下部。
- 保留按压回弹、标签让位和主题径向切换，并继续支持 reduced-motion。
- Android 8–11 保留原有轻量玻璃回退，最低系统要求不变。
