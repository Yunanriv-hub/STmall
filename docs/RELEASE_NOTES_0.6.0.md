# STmall 0.6.0

本次版本新增完美校园智能水电只读查询，不包含任何自动打卡或签到功能。

## 重点更新

- “功能”和“我的”新增“完美校园”，两页继续保持相同的模块尺寸和位置。
- 支持学校代码、学号/工号查询账号绑定房间。
- 支持查看水电剩余、今日使用、累计购买/使用和近七日用量。
- 模块内可直接打开学校代码文档。
- 学校代码和学号只保留在当前界面状态，不写入磁盘。
- 新增完美校园响应解析测试。

## 安全边界

- 只使用 Apifox 文档中的 `getbindroom` 和 `h5_getstuindexpage` 查询。
- 不接入密码登录、短信登录、虚拟 device_id、健康打卡、校内定位签到、
  粮票任务、批量账号、定时提交或消息推送。
- 参考仓库使用关闭 TLS 校验、虚拟设备 ID 和自动提交，不会复制进入 STmall。

详细报告见 [PERFECT_CAMPUS_SECURITY_AUDIT.md](PERFECT_CAMPUS_SECURITY_AUDIT.md)。
