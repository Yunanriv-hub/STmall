# STmall 0.4.1

本次版本集中修复真机反馈的页面崩溃、返回路径和液态玻璃细节，并补齐首页 U净
扫码、自定义背景与设备改名。

## 重点更新

- 首页新增“U净扫一扫”，扫码后直接进入 U净设备页，取消或返回时回到首页。
- “我的”新增“U净账号”；从功能页或我的进入 U净后，分别返回原页面。
- 修复慧生活登录、管理账号、积分与消费记录、钱包与充值四个入口闪退。
- 修复 U净页面顶部重贴，统一功能页、我的页和设置页的进入/返回动画。
- 液态玻璃开关滑块改为纵向居中，点击与拖动均提供液态按压反馈。
- 补齐 Catalog 风格单选按钮；关闭液态玻璃后，按钮、单选控件、底栏和面板
  全部使用无模糊、无渐变高光的纯色平面回退。
- 日间/暗黑切换改为颜色渐变，文字保持在过渡遮罩上方。
- 支持本机背景图片、持久授权、重启恢复和恢复默认背景。
- 支持门锁、慧生活饮水机和 U净设备添加后重新命名。
- 设置页分别展示主页模块与功能页模块，U净扫一扫不会在功能页重复出现。
- STmall 继续保持闭源，不启用 GitHub 在线更新或自动下载。

## 验证范围

- OPPO PGGM10（Android 14，1080×2412）覆盖安装、冷启动、亮暗主题、三页切换、
  底栏拖动、模块开关、背景持久化、U净返回、慧生活四入口和扫码取消返回。
- U净真实账号支付与蓝牙开洗、慧生活扫码分流、NFC 实体标签写入仍需有对应
  账号、设备和标签的现场环境验证。
