# STmall 使用教程

本文适用于 STmall `0.3.5` 及之后的版本。

> STmall 是非官方个人项目。请只使用自己的账号，并只操作自己有权使用的
> 门锁、饮水和校园设施。完整责任边界见 [免责声明](../DISCLAIMER.md)。

## 1. 安装前准备

请准备：

1. Android 8.0 或更高版本、支持 Bluetooth LE 的手机。
2. 已安装并登录的官方天猫校园。
3. 已安装的 Shizuku。
4. 一根可传输数据的 USB 线，或 Android 11 及以上系统的无线调试能力。
5. 可选：支持 NfcA/Ndef 标签的手机和本人有权使用的 NFC 标签。

STmall 的包名是 `com.rea.campuslite`。从 GitHub Releases 下载 APK 后，根据
系统提示允许当前文件管理器或浏览器“安装未知应用”。

升级时直接覆盖安装即可。应用使用固定的本地签名证书，因此正常升级不会清除
已保存的登录态和门锁凭证。

## 2. 启动 Shizuku

首次同步登录、读取日志或抓取门锁凭证需要 Shizuku。已经保存的登录态和
离线门锁凭证在后续使用时不再要求每次连接 Shizuku。

### 使用无线调试

Android 11 及以上可在开发者选项和“无线调试”中启动 Shizuku。具体按钮名称
可能因厂商系统而不同。

### 使用 USB ADB

连接手机并确认 `adb devices` 能看到设备后，在 Shizuku 中选择通过 ADB
启动，或执行 Shizuku 管理器提供的启动命令。

启动后，在 Shizuku 的“已授权应用”中允许 STmall。

## 3. 同步官方登录态

1. 在官方天猫校园完成账号登录。
2. 打开 STmall，进入“我的”。
3. 点击“同步官方登录”或“重新同步”。
4. 看到“已同步官方登录”和脱敏账号信息后，说明身份校验成功。

### 普通 Shizuku 同步失败时

如果厂商 WebView 没有生成可读取的 Cookie 数据库，并且 STmall 提示无法读取
登录态，可在电脑上使用仓库附带的无 Root 导入脚本。

先确认 `adb` 可以正常访问手机：

```powershell
$env:ANDROID_HOME = '<Android SDK 目录>'
& "$env:ANDROID_HOME\platform-tools\adb.exe" devices -l
```

然后从仓库根目录运行：

```powershell
.\tools\ImportNoRoot.ps1 `
  -Adb "$env:ANDROID_HOME\platform-tools\adb.exe" `
  -Serial "<手机序列号>"
```

脚本完成后，进入 STmall 的“我的 → 同步官方登录”。同步成功后，立即删除
手机上的临时导入文件：

```powershell
& "$env:ANDROID_HOME\platform-tools\adb.exe" `
  -s <手机序列号> shell rm -f /data/local/tmp/campus_lite_cookies.json
```

Cookie 不会显示在终端输出中。不要把临时 Cookie 文件、完整 Cookie JSON 或
导出的日志上传到 GitHub Issue。

## 4. 录入门锁凭证

只在本人有权使用的门锁附近执行。

1. 打开 STmall 首页的“智能宿舍”。
2. 切换到“门锁”，点击“开始抓取”。
3. 保持 STmall 在后台，切回官方天猫校园。
4. 在官方“智能宿舍”中授权蓝牙权限，并对自己的门锁执行一次合法开锁。
5. 回到 STmall。门锁地址和 `activationKey` 会自动进入表单。
6. 检查设备名称和地址无误后点击保存。

保存完成后，回到首页点击圆形“一键开门”按钮即可使用本地蓝牙开锁。

`activationKey` 就是门锁钥匙。不要截图、复制到聊天、提交到 Issue 或上传
到网盘。若凭证泄漏，请在官方应用中重新授权或撤销权限，并删除本机旧凭证。

## 5. 校园饮水

1. 打开“智能宿舍 → 饮水”。
2. 确认账号状态显示“登录态可用”。
3. 扫描饮水机二维码，或手动输入设备编号。
4. 核对设备位置和出水类型后执行对应操作。

饮水接口依赖官方服务和登录态。官方服务更新后，接口可能暂时不可用。

## 6. 慧生活

首页“慧生活”入口与当前 STmall 使用同一包名和签名，不需要安装第二个应用。

1. 打开“慧生活 → 去登录”。
2. 选择“用水登录”，输入自己的手机号并完成图形验证码、短信验证码。
3. “积分登录”是可选项；使用对应的积分平台会话可增加任务来源。
4. 登录成功后可在控制页同步收藏设备、添加设备、启动或停止设备。
5. “我的”页可查看钱包、充值、积分和消费记录。

慧生活账户和设备 Token 使用 Android Keystore 加密。不要在截图中公开手机号、
Token、设备编号、充值订单或完整日志。

STmall 底部“我的”页提供两个入口：

- “天猫校园”进入原来的登录态、订单、地址和 Shizuku 管理页面。
- “慧生活”进入 STmall 原生慧生活我的页，可管理账号、积分、钱包、消费统计和
  自动任务。

从首页进入慧生活主界面后只保留“控制”和“任务”；旧“我的”已统一移入
STmall 底部“我的”。慧生活页面使用与 STmall 相同的主题模式，并且不显示
首页右上角的主题切换和设置按钮。

慧生活主页左上角提供返回按钮。智能宿舍、天猫我的、慧生活我的
和界面设置统一使用液态玻璃返回栏或玻璃状态面板。模块卡与“我的”入口卡在
按压时会轻微缩放并回弹。

### NFC 标签读写

1. 打开“慧生活 → 设备 → +”，点击“NFC 碰一碰”，确认系统 NFC 已开启。
2. 读取时，把 NfcA/Ndef 标签靠近手机背面。
3. 识别到设备编号后，可点击“添加到慧生活”，编号会自动填入添加设备页。
4. 写入时，填写自己的设备编号并点击“写入到 NFC 标签”，再次靠近空白或可写标签。
5. 写入格式为 `https://i.ilife798.com/nfc.html?q=<设备编号>`。

标签写入只适用于兼容的 NfcA/Ndef 标签。已锁定、加密或非 NDEF 标签可能无法
写入。当前版本不支持云卡模拟、HCE APDU 刷卡、支付卡或复制第三方门禁卡。

## 7. 首页与外观

- 点首页右上角月亮/太阳按钮，可在日间和纯黑暗黑模式之间切换。
- 点右上角齿轮，可打开界面设置。
- 首页模块可以分别显示或隐藏；关闭后首页会自动重排。
- 选择“恢复全部首页模块”可恢复默认布局。
- 字号使用 Android 的动态字体单位，会跟随系统字体缩放。

## 8. 订单与地址

“我的订单”和“地址管理”通过官方深链打开天猫校园页面。使用时需要安装官方
应用，并保持官方账号登录态有效。

如果点击后进入官方登录页，请先在官方天猫校园重新登录，再返回 STmall。

## 9. 隐私清理

- “清除本机登录态”只会删除 STmall 本地保存的会话。
- 删除门锁凭证不会修改官方应用或门锁硬件。
- Cookie、慧生活账户/Token 和门锁凭证均使用 Android Keystore 加密，不进入
  系统备份。
- 应用不会附带任何开发者账号、Cookie 或真实门锁钥匙。

## 10. 常见问题

### 无法同步登录

确认官方天猫校园已登录、Shizuku 正在运行，并且 STmall 已获得 Shizuku
授权。仍失败时使用上面的无 Root 导入脚本。

### 找不到门锁

确认手机蓝牙已开启、位置权限已授予、手机靠近门锁，并让 STmall 保持在前台。
先尝试“查电量”或重新连接。

### 开锁失败

确认保存的是自己的门锁凭证，手机与门锁距离足够近，门锁电量正常。不要连续
发送大量开锁帧。若问题持续，删除并重新录入凭证。

### 页面升级后功能不可用

官方接口可能发生变化。请先查看 GitHub Releases 和 Issues；提交问题时不要
包含 Cookie、`activationKey`、完整手机号、门锁序列号或完整日志。

### NFC 没有反应

确认手机支持 NFC、系统 NFC 已开启，并且标签靠近手机背部 NFC 天线。读取失败时
先点击“仅读取标签”重试；写入失败时确认标签不是只读状态。
