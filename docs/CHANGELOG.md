# 更新记录

## 0.3.4

- 液态玻璃改用官方 Backdrop 背景采样、模糊和圆角透镜渲染。
- Android 12 及以上启用真实背景模糊，Android 13 及以上增加折射、深度和色散。
- 首页模块、图标底盘、一键开门、快捷按钮和底部栏统一为液态玻璃。
- STmall“我的”双入口、设置页卡、NFC 页、扫码页和模块返回栏接入同一玻璃体系。
- 慧生活“控制/任务”底栏及选中胶囊改为双层 Backdrop 透镜。
- 两套底部胶囊支持跟手拖动，选中态颜色与图标在标签之间连续渐变。
- 松手后按最近标签弹簧吸附，并执行方向一致的页面滑入滑出。
- 增加低对比背景光斑，让玻璃能够实际采样、模糊和折射背景。
- 修复暗黑模式中透明 Scaffold 未设置内容颜色导致的黑色文字重叠。
- 只启用“一键开门”时，将开门圆钮下移到更易点击的中下部。
- Android 8–11 自动保留兼容玻璃样式。
- 升级 Kotlin 2.2.21、Compose 与 Android Gradle Plugin 以使用官方库。

## 0.3.3

- 慧生活底部“控制/任务”改为浮动液态玻璃胶囊，选中标签使用弹簧移动。
- 标签选中时轻微放大，手指按压时图标和文字同步回弹。
- 首页模块卡与“我的”双入口卡增加弹簧式按压反馈。
- “我的”双入口改为半透明玻璃卡，增加边缘高光和柔和阴影。
- 所有模块子页统一增加液态玻璃返回栏或玻璃状态面板。
- 慧生活主页左上角增加玻璃返回按钮。
- 主题切换保留触摸点径向扩散，并在系统关闭动画时直接切换。
- 液态玻璃视觉参考 AndroidLiquidGlass 的光学层与选中透镜原则。

## 0.3.2

- 将 STmall“我的”改为“天猫校园”和“慧生活”两个模块入口。
- 将慧生活账户、积分、钱包、消费统计和自动任务迁移到 STmall 原生“慧生活我的”页。
- 首页慧生活入口改为 STmall 统一黑/薄荷绿主题，并隐藏旧页面中的“我的”页签。
- 进入慧生活及其“我的”页时不再显示 STmall 首页的主题切换和设置按钮。
- 统一慧生活模块与 STmall 的主题配色。

## 0.3.1

- 将首页主题切换和设置按钮改为 Scaffold 固定顶栏，不再覆盖标题区域。
- 首页有模块时不再显示大标题；只有关闭全部模块时才显示空状态引导标题。
- 首页保持单屏布局，不启用滚动；小屏使用紧凑模块卡和小型开锁圆钮。
- 修复两列模块卡内部标题、副标题换行或被裁切的问题。
- 已验证 1080×2378 与 720×1280 / 320dpi 下四个模块、开锁区和底栏同屏显示。

## 0.3.0

- 将 life-798 的慧生活核心能力作为同一 STmall 应用内的 `life798` 模块接入。
- 增加慧生活多账户、饮水设备启停、收藏设备、钱包、充值、积分、签到和账单。
- 增加慧生活桌面小部件、“启动设备”快捷磁贴和消费通知。
- 增加 NfcA/Ndef 标签读取、写入和 `nfc.html?q=<设备编号>` 碰一碰回填。
- 慧生活账户和 Token 改为 Android Keystore AES-GCM 加密存储。
- 保持现有天猫校园饮水、Shizuku 登录同步、蓝牙门锁和离线开门功能。
- 增加 life-798 MIT 许可与来源说明。
