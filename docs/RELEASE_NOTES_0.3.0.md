# STmall 0.3.0

本次更新把慧生活核心能力融入现有 STmall，而不是增加第二个独立应用。

- 多账户、独立用水与积分登录
- 慧生活饮水设备启停、收藏和别名
- 钱包余额、支付宝充值、积分、签到和消费账单
- 桌面小部件、快捷设置磁贴和消费通知
- NfcA/Ndef 标签读取、写入与设备编号回填
- 慧生活账户和 Token 使用 Android Keystore AES-GCM 加密
- 保留天猫校园饮水、Shizuku 登录同步、蓝牙门锁和离线开门

当前版本不包含慧生活云卡 HCE、APDU 刷卡、支付卡或第三方门禁卡复制。NFC
