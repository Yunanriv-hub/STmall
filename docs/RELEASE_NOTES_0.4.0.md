# STmall 0.4.0

本次版本将 STmall 重构为“主页 / 功能 / 我的”三页结构，并加入 U净洗衣机模块。

## 重点更新

- 主页仅保留一键开门与一键接水，功能页集中展示智能宿舍、慧生活和 U净。
- 三段底栏支持拖动、渐变选中和弹簧吸附；模块进入与返回动画统一。
- 设置页分别管理主页模块与功能页模块，避免重复开关。
- U净支持登录、扫码、多设备收藏、状态查询、订单倒计时、支付宝支付、
  Nordic/Cypress 蓝牙启动和机身时间同步。
- U净凭据与设备信息改用 Android Keystore AES-GCM 加密。
- 修复慧生活入口闪退、一键接水长按白色矩形、暗色文字对比度和设置返回跳动。
- 液态玻璃控件缩短跟手位移，开关点击和拖动具有一致的液态反馈。
- 在线更新与 GitHub 请求已停止。

U净实际开洗和支付需要有效的 U净 账号、设备现场测试与用户确认。
