# STmall 0.5.0

本次版本新增胖乖生活核心能力，并集中修复扫描页、液态玻璃和页面转场。

## 重点更新

- 功能页和我的页新增“胖乖生活”；首页新增胖乖设备“扫一扫”。
- 胖乖生活支持短信登录、扫码设备、最近设备、服务项和历史订单。
- 胖乖 Token 使用 Android Keystore AES-GCM 保存，不复制参考仓库的明文存储和日志实现。
- 首页“扫一扫”和“U净扫一扫”并排展示，均进入独立扫描页。
- 扫描页只显示“取消扫码”，顶部提示和按钮外围重复框已移除。
- 首页两个长按选择弹窗改为液态玻璃面板。
- 慧生活主要 Card/Surface 统一改用 Backdrop 玻璃容器。
- 功能页进入慧生活时底栏保持“功能”选中，返回路径同步修复。
- 页面转场使用无过冲弹簧并固定顶层布局尺寸，移除结束/开头跳动。
- 主题遮罩改为轻透明径向色层，背景图在切换全过程保持可见。

参考仓库安全审查结论：不得原样复制或原样安装；STmall 仅独立实现协议并采用加密存储。
