# Cumpus 0.6.12

- 修复桌面快捷方式和下拉磁贴偶发无法启动。
- 快捷方式每次启动动态刷新，覆盖安装后不再残留失效入口。
- 下拉磁贴先解锁再启动，失败时回退系统入口并显示可读提示。
- 首次启动引导加入后台运行白名单，降低 ColorOS 冻结导致的启动失败。
- 钥匙站抓取改为回看 3 分钟、多缓冲区监听和环形缓冲。
- 扩展门锁凭证写法，并在 root 环境增加 TLog 文件兜底。
- TLog 兜底使用 Android 8 兼容的有界读取，避免旧系统触发 API 33 调用崩溃。
- 抓取界面显示多轮进度和脱敏失败诊断。

本版本构建使用 `isMinifyEnabled = false`，未启用代码混淆。
