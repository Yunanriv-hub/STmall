# STmall 0.4.2

本次版本集中统一扫描体验、页面布局与动画反馈，并修复 U净页面的顶部重叠和
工具按钮换行。

## 重点更新

- 所有扫码按钮统一打开独立 `DeviceScanActivity`，扫描页只显示“取消扫码”。
- 移除不再使用的 JourneyApps 扫描页和依赖。
- “功能”和“我的”使用相同页头、间距和 108dp 模块卡；三张卡片边界完全一致。
- 三页切换改为可打断的全宽弹簧滑动，移除会让画面发虚的同步淡出、缩放与滑动组合。
- 主题切换时颜色动画和径向遮罩同步开始，状态栏与导航栏也同步渐变。
- U净顶部改为纵向布局，“手动输入”和“退出账号”不再覆盖返回按钮。
- U净“全部刷新、导入设备、导出设备”改为纵向满宽排列，文字不再换行。

## 验证范围

- OPPO PGGM10（Android 14，1080×2412）验证统一扫描页、取消返回、模块边界、
  快速连续切页、主题切换中间帧和 U净未登录顶部布局。
- U净登录后的“手动输入、退出账号、导入、导出”布局由同一纵向容器控制；
  实际账号操作仍需有效 U净账号验证。
